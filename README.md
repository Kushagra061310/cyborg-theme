Techfest CA Task: Cyborg Landing Page

A responsive, cybernetic-themed landing page built for the IIT Bombay Techfest College Ambassador program.

Core Architecture

Framework: Next.js (App Router)

Styling: Tailwind CSS v4

Deployment: Vercel

Technical Implementations

Interactive UI: Utilized React useState and useRef to map client mouse coordinates for a dynamic spotlight hover gradient.

Custom Animations: Engineered pure CSS keyframes to create a zero-dependency text glitch effect.

Responsive Layout: Implemented a CSS Grid architecture that natively collapses for mobile viewports without horizontal overflow or viewport breaking.
